Zugangsdaten, die ein OIDC-Token für die Authentifizierung per Workload Identity Federation bereitstellen (erfordert Dependency-Track v5.2.0 oder neuer). Hierfür eignet sich ein "OpenID Connect id token" aus dem Plugin OpenID Connect Provider. Das Token wird einmal pro Build gegen ein kurzlebiges Zugriffstoken getauscht, sodass kein API-Schlüssel gespeichert werden muss. Falls angegeben, hat es Vorrang vor dem API-Schlüssel.
